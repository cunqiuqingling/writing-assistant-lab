# Advanced Local OCR Companion（0.8.0，可选实验功能）

高级本地OCR是可选、实验性功能，不是扫描PDF的默认入口。

普通扫描文字应优先使用无需安装的浏览器OCR。只有浏览器OCR效果不足、电脑配置较好且用户愿意承担较长安装和首次模型准备时间时，才考虑安装PaddleOCR-VL连接器。

## 安全边界

- 服务只监听`127.0.0.1:8765`。
- 正式网站和本地测试地址需要配对令牌。
- 页面图像只在浏览器与本机连接器之间传递。
- 临时图像在任务结束后删除。
- 安装失败不影响网站其他功能。

## 安装前提醒

网页必须先展示性能、磁盘、网络和兼容性提示，用户勾选确认后才跳转安装说明。安装器要求Apple Silicon、至少8 GB可用磁盘，并使用Python 3.10–3.12；Python 3.13会被拒绝。

## 下载中断

安装器为pip增加超时、重试和日志。模型源可选BOS、ModelScope、Hugging Face或AIStudio。网络中断后可以重新运行安装器；也可以运行`cleanup_incomplete_install.command`彻底清理不完整环境。
