# Contributing

Thanks for helping improve Writing Assistant.

## Good contributions

- focused bug fixes;
- accessibility improvements;
- clearer learning instructions;
- additional original or clearly licensed practice materials;
- tests for local storage, backup and import behavior;
- UI improvements that keep the project lightweight and local-first.

## Before opening a pull request

1. Do not include personal practice data or backup JSON files.
2. Do not include copyrighted IELTS essays, books or articles without redistribution permission.
3. Keep the project free of tracking scripts and mandatory cloud services.
4. Test Sentence Lab, Paragraph Lab, Practice Library, backup and restore.
5. Explain the problem and the intended user benefit.

## Deployment boundary

Pull requests and forks do not automatically modify the live Cloudflare deployment. The maintainer reviews and deploys production changes separately.
