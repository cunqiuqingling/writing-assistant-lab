# Contact / 联系项目

## General feedback

Use public GitHub Issues for reproducible bugs, feature requests and non-sensitive documentation feedback:

`https://github.com/cunqiuqingling/writing-assistant-lab/issues`

Remove API keys, identity information, unpublished work, patient information and restricted source material before posting.

## Security, credentials and copyright evidence

Do not post exploitable vulnerabilities, live credentials, identity documents or copyright evidence in a public Issue.

Private options:

1. GitHub Private Vulnerability Reporting, when available:
   `https://github.com/cunqiuqingling/writing-assistant-lab/security/advisories/new`
2. A private contact method on the maintainer's GitHub profile:
   `https://github.com/cunqiuqingling`

Before broad commercial or institutional promotion, the project should add a dedicated domain email.

Public HTML: `/legal/contact.html`.
