WRITING ASSISTANT · 0.8.1

隐私政策

说明本地浏览器存储、基础设施日志、可选AI、Wikimedia和OCR功能的数据流。

生效日期：2026年7月28日 · 最近更新：2026年7月28日

1. 适用范围与项目维护者

本政策适用于 Writing Assistant 官方公开站点及其浏览器端功能。项目由 GitHub 仓库维护者独立维护，不设用户账号系统、共享用户数据库、广告系统或站内行为分析服务。

2. 默认保存在浏览器中的数据

  • 句子与段落练习答案、拆解笔记、计划和进度；
  • 自建练习材料、导入文档、章节编辑和本地标题覆盖；
  • 文件夹展开状态、界面偏好和普通JSON备份所包含的数据；
  • 浏览器支持时，由使用者授权的备份目录句柄；
  • 可选AI设置，以及主动选择“加密保存”时的本地加密密钥数据；
  • 可选高级OCR连接器的本地配对令牌，该令牌不进入普通JSON备份。

使用同一设备、同一浏览器配置文件的人可能看到这些本地数据。共享设备上应使用独立系统账户或浏览器配置文件。

4. BYOK AI边界

AI功能默认关闭。只有在使用者配置第三方提供商并主动发起请求时，浏览器才会把当前选中的参考文本直接发送给该提供商。学习者自己的仿写、笔记、标签、写作计划和练习进度不应进入该请求。

项目维护者不运营AI代理服务器，也不会从正常功能中收到API密钥或AI请求正文。第三方提供商如何保存和处理请求，由其自身隐私政策、服务条款和所在地区规则决定。

5. 文件导入与OCR

TXT、Markdown、EPUB、DOCX和PDF由浏览器端JavaScript解析。正式版文档解析器随本站静态资源提供；源文件与提取后的正文不会发送给项目维护者。

浏览器英文OCR只在使用者主动启动后加载同源Tesseract.js资源，并在浏览器内处理页面图像。高级PaddleOCR-VL连接器是可选实验功能，仅绑定本机回环地址。

6. 数据保留、备份与删除

项目维护者通常无法访问或替使用者恢复浏览器中的本地数据。使用者可以通过“Data & Backup → 清空本地练习数据”删除站点数据，也可以在浏览器设置中清除本站存储。重要练习应定期导出JSON备份。

7. 未成年人

本工具不主动收集年龄或身份信息。未成年人使用第三方AI、Wikimedia或其他外部服务时，应在监护人指导下阅读相应服务规则，避免提交个人敏感信息。

8. 政策更新与联系

功能、基础设施或外部服务发生重要变化时，本政策会同步更新并标明日期。一般问题可通过项目GitHub Issues提出；涉及漏洞、凭据、身份材料或版权证明的内容应使用私密渠道。

English summary

Practice data, imported documents and notes are stored in the current browser by default. Ordinary connection metadata may be processed by Cloudflare. AI requests are sent directly to the provider selected by the user and contain only selected reference text; learner writing and progress are excluded. Wikimedia requests occur only after user action. Browser OCR remains local; advanced OCR uses a loopback service.

Writing Assistant 是本地优先的开源英语写作练习工具。政策文本用于说明当前产品行为，不构成针对任何人的法律意见。
