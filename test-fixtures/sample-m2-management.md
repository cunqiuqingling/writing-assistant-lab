# Chapter One · Stable Identifiers

Changing a document title should not change the underlying material identifier. A learner who renames a card should still be able to return to the same saved chapter progress.

# Chapter Two · Source Revision

Changing the source text is different from changing a label. When the original chapter is rewritten, an old imitation may no longer correspond to the same sentence or paragraph.

# Chapter Three · Selective Cleanup

A safe editor should remove only incompatible progress. Work attached to untouched chapters should remain available after another chapter is split, merged, or deleted.
